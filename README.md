# 🍁 메이플스토리 보스 수익 및 득템 정산 계산기

메이플스토리 캐릭터들의 일간/주간/월간 보스 결정석 수익과 파티원 간 득템 분배금을 간편하게 관리하고 계산해 주는 웹 기반 유틸리티 프로그램입니다.

---

## ✨ 주요 기능

* **일간 / 주간 / 월간 보스 주기별 관리**: 
  * 넥슨 공식 보스 주기에 맞춰 완벽하게 분리된 탭 제공
  * 월간 보스(검은 마법사 등)가 주간 12개 제한 슬롯을 소모하지 않도록 독립 계산
* **정확한 수익 대시보드**: 
  * **주간 환산**: (일간 보스 × 7일) + 주간 보스 + 월간 보스 + 주간 득템
  * **월간 환산**: (일간 보스 × 30일) + (주간 보스 × 4주) + 월간 보스 + (주간 득템 × 4주)
  * 월드 내 결정석 주간 판매 제한(90개) 슬롯 자동 카운트 바 표시
* **보스 득템 분배 정산**: 
  * 경매장 수수료 자동 계산 (MVP 실버 이상/PC방 3%, 일반 5%, 직거래 0%)
  * 파티 인원수(1~6인)별 내 몫의 실 수령액 자동 산출
* **넥슨 오픈 API 연동**: 
  * 캐릭터 닉네임 입력 시 공식 API를 통한 자동 정보 조회 (레벨, 직업, 캐시 이미지 연동)
  * 수동 직접 입력 모드 병행 지원
* **사용자 편의 기능**:
  * 다크 모드 / 라이트 모드 테마 토글
  * 캐릭터별 보스 진행 내역 원터치 초기화 기능

---

## 🚀 사용 방법

1. **API Key 등록 (선택)**: 
   * 상단의 `🔑 Key 등록` 버튼을 클릭합니다.
   * [넥슨 오픈 API 포털](https://openapi.nexon.com/)에서 무료로 발급받은 API Key를 입력합니다.
2. **캐릭터 추가**: 
   * API 자동 조회 또는 수동 직접 입력 방식을 통해 본인의 캐릭터들을 등록합니다.
3. **보스 클리어 체크**: 
   * 일간, 주간, 월간 탭에서 각 캐릭터가 격파하는 보스와 파티 인원수를 체크합니다.
4. **수익 및 득템 정산**: 
   * 상단 대시보드에서 예상 수익을 확인하고, 득템 정산 탭에서 아이템 분배금을 계산합니다.

## ⚠️ 보안 및 주의사항

* **API Key 보안**: 입력하신 넥슨 오픈 API Key는 서버로 절대 전송되지 않으며, 사용자 본인의 **브라우저 로컬 스토리지(`localStorage`)**에만 안전하게 보관됩니다.
* **보스 이미지 적용**: 보스 아이콘 이미지를 정상적으로 표시하려면 프로젝트 루트 폴더 내에 `images` 폴더를 만들고, `bosses.csv`의 보스 이름과 정확히 일치하는 PNG 파일(예: `스우.png`, `검은 마법사.png`)을 위치시켜 주세요. (이미지 파일이 없어도 첫 글자 뱃지로 대체되어 정상 작동합니다.)
