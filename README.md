# 🍁 Maple Calculator (메이플 보스 수익 및 득템 정산기)

메이플스토리의 주간/월간 보스 결정석 수익과 파티 득템 판매 분배금을 간편하게 계산하고 관리할 수 있는 반응형 웹 애플리케이션입니다.

사용자가 별도로 넥슨 API 키를 발급받거나 입력할 필요 없이 **캐릭터 닉네임만으로 공식 데이터를 자동 연동**하며, **Supabase 클라우드 동기화**를 통해 PC와 스마트폰 어디서나 데이터를 이어서 관리할 수 있습니다.

---

## ✨ 주요 기능

* **닉네임 기반 캐릭터 자동 연동 (Proxy API)**: 넥슨 오픈 API 키 입력 없이 캐릭터 닉네임만 입력하면 외형, 직업, 레벨 정보를 즉시 조회하여 등록합니다. 수동 입력 추가도 지원합니다.
* **스마트 보스 결정석 정산**: 보스별 난이도 및 클리어 인원수(1~6인)에 맞춘 1/N 계산, 캐릭터별 최대 12개 및 계정당 주간 90개 판매 상한 자동 필터링을 지원합니다.
* **주간 / 월간 수익 대시보드**: 주간 보스와 월간 보스(검은 마법사, 세렌 등)를 분리 집계하여 주기별 예상 수익을 한눈에 파악할 수 있습니다.
* **보스 득템 분배 계산기**: 옥션 수수료 감면(기본 5% / MVP 실버 이상 및 PC방 3%) 옵션, 파티원 수 분배 계산, 빠른 금액 증액 버튼(100만~100억) 및 직접 입력을 지원합니다.
* **크로스 플랫폼 클라우드 동기화**: 간편 ID와 PIN 번호 설정만으로 PC와 모바일 간 실시간 데이터 동기화가 가능하며, 오프라인 상태에서도 LocalStorage를 통해 기존 데이터가 유지됩니다.
* **모바일 최적화 반응형 UI**: 가로 스크롤이나 버튼 깨짐 없이 스마트폰 화면 비율에 최적화된 3×3 그리드와 다크/라이트 모드를 제공합니다.

## 📖 사용 방법

1. **캐릭터 등록**
   * **API 자동 조회**: 상단 좌측 패널에서 본인의 캐릭터 닉네임을 입력하고 `+ 추가`를 누릅니다.
   * **수동 직접 입력**: 닉네임 조회가 되지 않거나 가상 캐릭터를 추가할 경우 '수동 직접 입력' 탭에서 닉네임, 직업, 레벨을 기입해 등록합니다.
2. **보스 클리어 현황 체크**
   * 보유 캐릭터 목록에서 정산할 캐릭터를 선택합니다.
   * `주간 보스` 또는 `월간 보스` 탭으로 이동하여 클리어한 보스의 난이도 버튼을 클릭합니다.
   * 파티 격파인 경우 `+` / `-` 버튼을 눌러 파티 인원(1~6인)을 설정하면 1인당 결정석 가격이 자동 반영됩니다.
3. **득템 분배금 정산**
   * `득템 정산` 탭으로 이동합니다.
   * 아이템 이름, 획득 날짜, 판매 금액을 입력합니다. (빠른 추가 버튼을 눌러 단위를 즉시 증액할 수 있습니다.)
   * 본인의 옥션 수수료 혜택(3% / 5%)과 파티 분배 인원을 설정한 뒤 `등록`을 누르면 내 실 수령액이 계산되어 누적 내역에 추가됩니다.
4. **기기 간 데이터 연동 (클라우드 동기화)**
   * 상단 헤더의 `☁️ 계정 연동` 버튼을 클릭합니다.
   * **계정 만들기**: 사용할 동기화 ID와 비밀번호(PIN)를 입력하여 클라우드 계정을 생성합니다.
   * **로그인**: 다른 기기(모바일 등)에서 동일한 ID와 비밀번호를 입력해 저장된 캐릭터 및 보스 체크 데이터를 즉시 불러옵니다.

## 🔒 보안 및 주의사항

* **API Key 보안 관리**: 클라이언트(프론트엔드) 코드에 개인 넥슨 오픈 API 키를 하드코딩하지 마세요. 넥슨 API 키는 반드시 Supabase Edge Functions의 **환경변수(`Secrets`)**에 등록하여 프록시 형태로 호출해야 브라우저를 통한 키 탈취를 방지할 수 있습니다.
* **API 호출 제한 (Rate Limit)**: 개발자 개인의 API 키를 프록시로 공유해 사용하는 구조이므로, 다수의 사용자가 동시에 캐릭터를 조회할 경우 넥슨 Open API의 초당/일일 호출 제한에 도달할 수 있습니다.
* **동기화 계정 비밀번호(PIN) 관리**: 본 서비스의 클라우드 계정은 편의를 위해 간편 ID와 PIN 번호 방식으로 구현되어 있습니다. 금융/포털 사이트 등에서 사용하는 주요 비밀번호와 동일한 값을 사용하지 말고 간단한 아이디와 비밀번호를 설정하는 것을 추천합니다.
* **결정석 판매 상한 규칙**: 메이플스토리 게임 내 규칙에 따라 주간 결정석 판매는 **메이플 ID당 주간 최대 90개**, **캐릭터당 주간 최대 12개**로 제한됩니다. 계산기 대시보드는 이 규칙에 맞춰 최고가 순으로 자동 정렬 집계합니다.
* **정기 점검 및 가격 변동**: 매주 목요일 오전 0시를 기준으로 주간 보스 클리어 및 득템 주간 정산이 리셋되며, 게임 패치로 인한 결정석 가격 변동 시 `bosses.csv` 파일 갱신이 필요합니다.

## 🛠 기술 스택

* **Frontend**: HTML5, Tailwind CSS, React 18 (Babel Standalone CDN)
* **Backend / Serverless**: Supabase Edge Functions (Deno Runtime)
* **Database**: Supabase PostgreSQL
* **Open API**: Nexon Open API (MapleStory)
